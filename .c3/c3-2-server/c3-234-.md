# observability

## Goal

Own the server's process- and turn-level observability: the pure instrument facade domain code calls, the single adapter that exports it, and the alert rules that turn the exported fleet data into a GitHub ticket.

## Parent Fit

| Field | Value |
| --- | --- |
| Container | c3-2 (server) |
| Parent Goal Slice | "Report what the running server is doing, and notice when it degrades" |
| Category | foundation |
| Lifecycle | Started once at boot; the export half is toggled at runtime by the telemetry setting |
| Replaceability | Replaceable behind the facade — swapping OTel for another backend touches only the adapter |

## Purpose

Gives every other component a dependency-free way to record a span, a counter or a histogram (`src/server/observability.ts`), and keeps every side effect — the OTel SDK, exporters, `process.memoryUsage`, heap snapshots — in the one adapter the side-effect seal exempts (`src/server/otel.adapter.ts`). Owns the fleet's alert definitions (`src/ops/alerting/`), because a threshold is only meaningful next to the instrument it reads, and a metric renamed without its rule is a rule that silently matches nothing.

Non-goals: deciding WHAT is worth instrumenting — that stays with the component that owns the code path; and rendering telemetry in the UI.

## Change Safety

| Risk | Trigger | Detection | Required Verification |
| --- | --- | --- | --- |
| A renamed instrument leaves an alert rule matching no series, which looks exactly like a healthy fleet | Metric name edited at the call site only | Rules suite compares every kanna_* token in a query against the facade's own constants | bun test --conditions production src/ops/alerting/rules.test.ts |
| Histogram buckets revert to OTel defaults, silently making every latency quantile meaningless | View removed or instrument renamed without updating the view list | Bucket test asserts turn-length durations land in distinct finite buckets | bun test --conditions production src/server/observability.test.ts |
| Instrumentation swallows or alters a wrapped call's result | withSpan rewritten with an inline try/catch | Pass-through and rethrow cases in the facade suite | bun test --conditions production src/server/observability.test.ts |
| A leaked test meter provider swallows another suite's metrics | A test registers the in-memory recorder without disposing it | Recorder disposal clears the api global and the facade instrument cache | bun test --conditions production src/server |
| Applying alert config deletes notification routes this repo does not own | Policy rebuilt instead of merged | mergePerfRoute preserves the tree and owns one route by contact-point name | bun test --conditions production src/ops/alerting/webhook-payload.test.ts |
