05  /  Boards

A card that moves because you moved it

The board’s design brief is already strict: a column at rest is the page with a 1px divider, its colour is a 6px dot, the drop target is a 1px line that exists only while dragging, and a healthy card shows nothing at all. Motion has to respect that — so it adds exactly three things: the lift that says a card is in your hand, the line that says where it will land, and the travel between the two. Nothing gains a shadow at rest.

anime.js — the new-session timeline
import { createTimeline, stagger, eases } from "animejs"

const reduce = matchMedia("(prefers-reduced-motion: reduce)").matches
const tl = createTimeline({ defaults: { ease: "out(3)" } })

tl.add(rowsBelow, {                       // 1 · make room
    y: [0, ROW_H], duration: 180,
    delay: stagger(14),
  }, 0)
  .add(spawnRow, {                        // 2 · born
    height: [0, ROW_H], opacity: [0, 1],
    duration: 200, ease: eases.outBack(1.4),
  }, 120)
  .add(spawnRail, { scaleY: [0, 1], duration: 200 }, 140)
  .add(sidebar, {                         // 3 · step back
    scale: [1, .972], x: [0, -8], opacity: [1, .55],
    duration: 220,
  }, 260)
  .add(surface, { scale: [1.035, 1], opacity: [0, 1], duration: 220 }, 260)
  .add(flyer, { ...flipTo(navTitle), duration: 240, ease: "out(4)" }, 280)
  .add(composer, {                        // 4 · fly up, focused
    y: [56, 0], scale: [.96, 1], opacity: [0, 1],
    duration: 240, ease: createSpring({ stiffness: 190, damping: 16 }),
  }, 420)
  .add(focusSweep, { scaleX: [0, 1], duration: 220 }, 470)
  .add(emptyFlower, {                     // 5 · transcript opens
    scale: [.1, 1], filter: ["blur(12px)", "blur(0px)"],
    opacity: [0, 1], duration: 280, ease: "out(4)",
  }, 600)
  .then(() => typeEmptyState(19))         // 19ms/char, as today

if (reduce) tl.complete()                 // one frame, no travel
