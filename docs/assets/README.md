# Kanna visual assets

## Kanna Loop infographic

[`kanna-loop-infographic.html`](./kanna-loop-infographic.html) explains the notification-driven Kanna Loop in Vietnamese.

The visual centers the tracking file as the durable source of truth. Each iteration reads one next chunk, delegates focused work, verifies the result, records progress, and uses a completion notification to start the next fresh-context iteration.

Open the file in a modern browser. The infographic is a self-contained HTML document with an accessible inline SVG.
